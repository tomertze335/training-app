# Prompt Trainer

כלי אינטראקטיבי פשוט לייעוץ ופרומפטים מוכנים ל־AI.
 
## הפעלה
1. פתח את תיקיית `training-app` ב־VS Code.
2. פתח את `index.html` עם Live Server.
3. בחר טאב ונסה את הניווט, הטבלה והלחצן "העתק".

## מבנה הקבצים
- `index.html` - דף הבית של האפליקציה.
- `styles.css` - עיצוב לבן, מודרני וקריא.
- `scripts/data.js` - נתוני המוצר, מאמן, פרומפטים ותוכנית.
- `scripts/ui.js` - רינדור דינמי של הטאבים והתוכן.
- `scripts/app.js` - התחלת היישום והגדרת האירועים.
 - `scripts/tests/test-runner.html` - דף בדיקות אוטומטי בדפדפן.

## תכונות עיקריות
- ניווט Drawer + טאבים בעברית.
- ניהול פרומפטים עם יצירה, עריכה ומחיקה.
- ייצוא JSON וייצוא כל הפרומפטים להעתקה.
- שמירת פרומפטים ב־localStorage.
- תמיכה ב־RTL ונראות לבנה.
- תכנית עבודה מורחבת ל־10 שלבים עם המשך מקצועי.

## בדיקות
פתח את `scripts/tests/test-runner.html` עם Live Server כדי להריץ בדיקות UI פשוטות (טאבים, העתקה, יצוא JSON).
- טבלה של פרומפטים ותצוגת תצוגה מקדימה.
- תוכנית עבודה פשוטה של חמישה שלבים.
