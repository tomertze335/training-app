# Blueprint חדש לפרויקט Prompt Trainer

## חזון
היישום שייבנה הוא כלי פשוט וקריא ב־HTML/CSS/JavaScript שמסייע ליועצים, מאמנים ומפתחים להכיר פרומפטים, לבדוק אותם ולהעתיק אותם לשימוש ב־AI.

## מבנה הפתרון
1. דף סטטי מבוסס דפדפן בלבד.
2. ניווט משמאל (Drawer) ומערכת טאבים עליונה.
3. טבלאות, כרטיסיות ואייקונים לשיפור הקריאות.
4. פוקוס על שלבים פשוטים שניתן לבנות ביום אחד.

## מסגרת הארכיטקטורה
| רכיב | תיאור | מטרה |
| :--- | :--- | :--- |
| Frontend סטטי | HTML, CSS, JavaScript | ממשק משתמש מהיר ונקי ללא צורך בשרת |
| ניווט רב-שכבתי | Drawer + טאבים | גישה מהירה לדשבורד, מאמן, פרומפטים ותוכנית העבודה |
| מאגר תכנים | קובץ JS מודולרי | ניהול טקסטים, פאזות ופרומפטים בקוד אחד שניתן להרחיב |
| פעולות משתמש | לחצן העתק ומודלי תצוגה | שימוש יומיומי פשוט לשיתוף פרומפטים וקריאה מהירה |

## ערכי המוצר
- פשוט לקריאה ולשימוש
- קל לתחזוקה ולהרחבה
- חזות לבנה ונקייה עם קונטרסט ברור
- תוכן ממוקד להתייעצות ולהעתקה ל־AI

## זרימת המשתמש
1. נפתח את היישום בדפדפן.
2. בוחרים טאב מתאי הניווט.
3. קוראים את החומר ב"Trainer" או ב"Dashboard".
4. עוברים לטאב "Prompts" ומעתיקים פרומפטים ישירות.
5. עוקבים אחרי "Plan" כדי להמשיך לפיתוח.

## מטרות ותוצרים ראשונים
- דף ראשי מודולרי עם ניווט ותוכן מחולק
- טבלת פרומפטים עם לחצן העתק
- אייקונים וטאבים לשיפור חוויית המשתמש
- תוכנית עבודה מפורטת ליום אחד
