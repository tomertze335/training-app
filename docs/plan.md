# תכנית עבודה - Planflow פשוטה ליום אחד

## כיוון כללי
המטרה היא לבנות ביישום אחד כלי HTML/CSS/JS פשוט שעוזר ליועצים ומפתחים לייעץ עם פרומפטים ל־AI.

## חמישה שלבים ליום אחד
1. **שלב 1 - מבנה בסיסי**
   - בניית קבצי HTML, CSS ו־JS פשוטים.
   - יצירת מסגרת ניווט ראשית ותוכן התחלתי.
2. **שלב 2 - טאבים ותפריט**
   - הוספת מערכת טאבים עליונה.
   - יצירת Drawer צדדי עם ניווט אייקונים.
3. **שלב 3 - טבלת פרומפטים**
   - הכנסת טבלה עם פרומפטים מוכנים.
   - לחצן "העתק" לטקסט.
4. **שלב 4 - תוכן מאמן**
   - הוספת קטעי מאמן והסברים.
   - הדרכה כיצד להשתמש ביישום.
5. **שלב 5 - עיצוב לבן ונקי**
   - עיבוד המראה ללבן ולנוח.
   - שיפור רספונסיביות ונראות.

## תוצר לכל שלב
| שלב | תוצר | למה זה חשוב |
| :--- | :--- | :--- |
| Phase 1 | דף סטטי מודולרי | יצירת בסיס לפיתוח מהיר |
| Phase 2 | ניווט טאבים ו-Drawer | חוויית משתמש ברורה |
| Phase 3 | טבלת פרומפטים | כלי מעשי לייעוץ והעתקה |
| Phase 4 | מאמן ותוכן הדרכתי | הנגשה למשתמש ולקהל יעד |
| Phase 5 | עיצוב לבן מקצועי | מראה נקי ונוח לקריאה |

## איך לבחון את ההצלחה
* האם היישום עובד בדפדפן דרך Live Server?
* האם ניתן לעבור בין טאבים ולראות תוכן חדש?
* האם ניתן להעתיק פרומפטים ישירות מהטבלה?
* האם הממשק נקי, לבן וקריא?

## תוכנית המשך - Plan 2
לאחר בניית המוצר הבסיסי, אפשר להמשיך לשכבה השנייה שתפתח יותר ערך ותמנף את הכלי לשימוש מקצועי.

1. **שלב 6 - ייצוא ושיתוף**
   - הוסף ייצוא JSON ו־CSV לנתוני הפרומפטים כדי להקל על שיתוף וייבוא בכלים אחרים.
   - אפשר שיתוף קישור ישיר לעמוד, הפקת קישור למייל ולקבוצות עבודה.
   - הכן את הפרויקט לפרסום ב־GitHub Pages על ידי אימות שהדף עובד ללא שרת צד.
   - תוצאה: משתמש יכול לייצא מאגר פרומפטים ולהעביר אותו הלאה בקלות.
2. **שלב 7 - ניהול תכנים מתקדם**
   - הוסף שדות תגיות וקטגוריות לשדות הפרומפטים.
   - אפשר חיפוש מתוחכם לפי שם, תוכן, קטגוריה ותג.
   - הוסף ממשק יצירה מהירה של פרומפטים חדשים ושמירתם ב־localStorage.
   - תוצאה: התוכן מאורגן ונגיש לכל משתמש.
3. **שלב 8 - שימוש חוזר וניהול היסטוריה**
   - הוסף אפשרות לסמן פרומפטים כמועדפים.
   - שמור היסטוריית פעולות של העתקות, עריכות ומחיקות.
   - אפשר שכפול פרומפט קיים לעריכה מהירה ולשימוש חוזר.
   - תוצאה: משתמשים יכולים לשחזר רעיונות ולבנות על עבודה קודמת.
4. **שלב 9 - התאמה אישית וחוויית משתמש**
   - הוסף תמיכה ב־light/dark mode ובמעבר בין RTL ל־LTR.
   - אפשר התאמת גודל טקסט, ערכת צבעים, ואייקונים מותאמים.
   - שפר את חוויית המשתמש עם קיצורי מקשים, סטטוס ברור והודעות מצבים.
   - תוצאה: ממשק גמיש ונעים לשימוש במצבים שונים.
5. **שלב 10 - אינטגרציה חיצונית**
   - חבר ל־API חיצוני של מודל AI או שירות LLM כדי לייצר תובנות וסיכומים.
   - הוסף אפשרות לטעינת קובצי JSON קיימים וייבוא נתונים חיצוניים.
   - בנה דשבורד שימוש שמציג מדדי העתקות, קטגוריות נפוצות ומעקב ביצועים.
   - תוצאה: כלי מקצועי עם חיבור לעולם AI וניתוח שימוש.
