# PRD חדש ליישום Prompt Trainer

## 1. תקציר מנהלים
היישום הוא כלי סטטי פשוט שמרכז מדריך ייעוץ לפרומפטים ופרומפטים מוכנים להעתקה. המטרה היא לייצר כלי קריא, נגיש וקל לתחזוקה ב־HTML/CSS/JavaScript.

## 2. מטרת המוצר
לספק דף עבודה לייעוץ ולהכנת מענה ל־AI:
- לראות תוכן מקצועי בצורה מסודרת
- לבחור פרומפטים מוכנים
- להעתיק אותם במהירות לשימוש ב־AI
- להבין את השלבים הבאים של הפיתוח

## 3. קהל יעד
| קהל | צורך | תוצאה צפויה |
| :--- | :--- | :--- |
| יועצי AI ומאמנים | טיפים ופרומפטים מוכנים | עבודה מהירה מול לקוח |
| מפתחי פרויקט | ארכיטקטורה ותוכנית עבודה | ממשק לבניית אבטיפוס | 
| משתמשים מתחילים | הסברים ברורים | הבנה של זרימת העבודה |

## 4. דרישות מוצר
| קטגוריה | דרישה |
| :--- | :--- |
| ממשק | ניווט עם Drawer + טאבים |
| עיצוב | רקע לבן, צבעים רכים, קריאות גבוהה |
| תוכן | דשבורד, מאמן, רשימת פרומפטים, שלבים |
| פונקציונליות | לחצן "העתק" לטקסט פרומפט |
| תחזוקה | קוד מודולרי ב־JS | 

## 5. מבנה התוכן
1. **Dashboard** – מציג קונספט, מטרות ומידע מרכזי.
2. **Trainer** – כולל הנחיות עבודה, איך להיעזר במידע ומה להעתיק.
3. **Prompts** – טבלה של פרומפטים מוכנים לשימוש.
4. **Plan** – חמישה שלבי פיתוח פשוטים להמשך.

## 6. חיבור למסמכים קיימים
- מה־Blueprint נשמר הרעיון לבניית כלי פשוט להצגת תוכן ופרומפטים.
- מה־Planflow נשמרו חמשת השלבים החזקים לבניית האפליקציה ביום אחד.
- מה־PRD הישן נשמר הצורך בפוקוס על ייעוץ, תחקיר ופרומפטים.

## 7. מדדי הצלחה
* ניתן להפעיל את היישום ב־Live Server ללא תלות בשרת.
* ניתן לבחור טאבים ולראות תוכן מיידי.
* ניתן להעתיק פרומפטים בטבלה בלחיצה אחת.
* העיצוב לבן ונקי, קריא לעין.
